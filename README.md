# ランダム恒星観測所

高校生向けの宇宙科学教材。天の川銀河の主系列星（O〜M型）を固定の確率分布から1個ずつ生成し、
恒星の物理量・構成元素・太陽とのサイズ比較・惑星系をインタラクティブに確認できる。
何度も生成するうちに「M型の赤色矮星が圧倒的に多く、O型・B型はほとんど出ない」ことを体験するのが中心的な教育体験。

## 使い方

```bash
npm install
npm run dev        # 開発サーバー (http://localhost:5173)
npm test           # テスト (Vitest)
npm run build      # 本番ビルド (dist/)
```

- 恒星のドット絵は 8 fps で自転し、低温で活動的な星（特にM型）ではフレアが起こる。速さは誇張した表現で、OSの「視差効果を減らす」設定がオンなら既定で停止（パネル内のボタンで再生／停止、設定は保存）。
- `#seed=xxxx` 付きのURLを開くと、その恒星系が再現される（共有リンク）。
- ページ下部「seed と開発者・先生向けツール」で、型を直接指定した生成（`seed@O` 形式）と seed からの再生成ができる。
  型指定生成は確率どおりではないため、観測数には数えない。

## 技術構成

React 19 + TypeScript + Vite。バックエンドなし（生成・履歴・お気に入りはすべてブラウザ内、保存は localStorage）。

```
src/
  types/          共有型（StarSystem, Star, Planet など）
  data/           科学パラメータ（UIから分離。モデル変更はここだけで済む）
    stellarTypes.ts     スペクトル型ごとの固定重み・温度/質量/半径の範囲・細分類・説明
    mainSequence.ts     質量→温度・半径の補間表、寿命表、IMF
    composition.ts      太陽表面組成、金属量分布、宇宙初期組成
    planetModel.ts      惑星数分布、軌道・サイズ・タイプの規則
    modelProvenance.ts  根拠の区分（A/B/C）と参考文献
  models/         生成アルゴリズム（純粋関数・seed で決定的）
    stellarGenerator.ts, planetarySystemGenerator.ts, systemGenerator.ts
  render/         ドット絵のピクセル生成（純粋関数）と canvas 描画
  storage/        履歴・お気に入り・観測数の保存
  hooks/          アプリ状態 (useObservatory)
  components/     UI
```

## 科学モデルとパラメータの区分

| 区分 | 意味 |
| --- | --- |
| A | 観測・文献に基づくパラメータ |
| B | 天文学的知見から導いた近似モデル |
| C | 本教育アプリ独自の仮定 |

| 項目 | 内容 | 区分 |
| --- | --- | --- |
| スペクトル型の割合 | O 0.00003% / B 0.13% / A 0.60% / F 3.00% / G 7.60% / K 12.10% / M 76.45%（太陽近傍の主系列星頻度の近似値）。抽選時に `fixedWeight / sum` で正規化 | A（値）+ C（銀河全体の代表として使うこと） |
| 型ごとの温度・質量・半径の範囲 | 要件の表どおり。O型は 30,000〜50,000 K, 16〜90 M☉ をモデル上限とした | A |
| 型の中の質量分布 | Kroupa (2001) IMF の形（軽い星ほど多い） | A/B |
| 質量→温度・半径 | 型境界と太陽 (1 M☉, 5772 K, 1 R☉) を通る両対数補間表＋小さなばらつき。境界を越えないよう丸め単位分内側にクランプ | B（＋ばらつき量は C） |
| 光度 | L = R² (T/5772)⁴ | B |
| 主系列寿命 | M ≤ 1: 100億年 × M/L、M > 1: 進化モデル値を丸めた表（O型 約300万〜1000万年） | B |
| 構成元素 | 太陽表面組成 (Asplund 2009) を [Fe/H] ~ N(−0.05, 0.2) でスケール。He は ΔY/ΔZ = 1.5、宇宙初期値 0.245 を下限 | A/B |
| 惑星数 | 0〜8個の固定分布（10/20/25/20/12/7/4/1.5/0.5%） | C |
| 軌道 | 内側から順に、周期比 ≥ 1.3、惑星数が多いほど平均周期比が小さい対数正規分布、まれに大きなすき間。恒星半径の3倍・ダスト昇華距離の半分より外。周期はケプラー第三法則 | A（ケプラー則）/ B / C |
| サイズ | サイズ帯の重み（小型ほど多い）を、スノーライン外で大型↑、0.1 AU 以内の巨大惑星↓、M型で巨大惑星↓、金属量で巨大惑星↑（10^(2[Fe/H])）と補正。系全体のサイズ傾向も共有 | B + C |
| タイプ | サイズで候補を決め、平衡温度・スノーラインで重みを補正（決定論的ではない）。タイプごとの半径範囲で整合性を保証 | C |
| 恒星アニメーション | 自転周期は高温星ほど短く（A・B型の速い自転の傾向を誇張）、フレア活動度は黒点活動の強さに比例（M型で最大、A型以上で0）。フレアは黒点付近で、seed とフレーム番号から決まる時刻に急増光→緩やかな減光 | B（傾向）+ C（速さ・頻度は誇張） |
| 見た目 | タイプ・温度区分・サイズからスタイルとパレットを決め、seed からドット絵を生成 | C（教育用イラスト） |

惑星系については観測データが不完全であるため、実際の天の川銀河の惑星系分布を再現したものとして扱わない。

## 再現性

すべての乱数は seed から導かれる。生成段階ごとに `seed::star`, `seed::planet-orbits` のように独立した乱数列を使うため、
ある段階のモデルを変えても他段階の結果はずれにくい。モデルの数値を変えたら `MODEL_VERSION`（`src/models/systemGenerator.ts`）を上げること。
お気に入りは生成済みデータ全体を保存するので、モデル変更後も保存時の内容で復元される。

## テスト

`src/models/*.test.ts`（科学モデル）と `src/App.test.tsx`（UI）。主な確認項目：

- 固定重みの保存と正規化、2万回生成・100万回抽選での型比率
- 7型の直接指定生成、各型の質量・温度・半径・寿命の範囲、境界をまたがないこと
- 質量と温度・半径・光度（正の相関）、寿命（負の相関・非線形）
- 構成元素の合計と範囲
- 惑星数分布、軌道の順序と間隔、恒星内部に入らないこと、ケプラー則
- サイズ分布、タイプとサイズの整合性、距離が決定論的ルールでないこと
- seed からの完全再現（ピクセル単位まで）
- 惑星のホバー／タップ表示、履歴10件、お気に入りの保存・再読み込み後の復元
